# Optional Python Layer

Baseline workflow: **Excel → SQL → Power BI → Decision**.

Use Pandas + NumPy when station-level EDA, repeatable transformations, outlier analysis or sensitivity testing would improve the work.

Suggested use here:
- Pandas: station/corridor profiling and projected-vs-actual gap analysis.
- NumPy: percentile-based opportunity thresholds and sensitivity calculations.

Python is optional and should not replace the governed SQL/Power BI KPI layer.
