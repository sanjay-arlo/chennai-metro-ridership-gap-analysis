# Chennai Metro Ridership Gap Analysis

> Business Analyst portfolio case study analysing station-level ridership versus planning projections to identify growth gaps and last-mile priorities.

## 🚀 Live Dashboard

**[Open the interactive dashboard](https://sanjay-arlo.github.io/chennai-metro-ridership-gap-analysis/)**

## Business question

**Which stations and corridors run furthest below projected ridership, and what actions could close the gap?**

## Dashboard

Compare actual versus projected demand, identify underperforming stations, evaluate last-mile connectivity and surface corridor-level intervention priorities.

## KPI logic

**Ridership gap %** = (Projected ridership − Actual ridership) / Projected ridership × 100.

## Dataset

Synthetic/illustrative station-quarter data is used for portfolio demonstration. It is not official CMRL station-level data.

## Business Analyst focus

The project demonstrates problem framing, KPI design, segmentation, root-cause hypotheses, stakeholder-oriented recommendations and decision-support dashboarding.

## Production upgrade

Use verified smart-card tap data, official planning baselines, feeder-transit ridership, station catchments and time-series fare/service variables. Add governed refresh, anomaly checks and station master-data controls.

## Limitation

Portfolio analysis only; not an official transport-planning report.
